# Premium — single PRO tier (mobile IAP)

## Free (one account)

- **Skin** (Results dashboard)
- **Progress** (history / trends)
- **1 scan per calendar day**

## PRO (RevenueCat entitlement `premium`)

- Everything in Free
- **Face** analysis
- **Glow Up** recommendations / routines
- **Unlimited scans**

There is no separate PRO+ tier.

## Native only

Purchases run via RevenueCat on iOS/Android (`Paywall.tsx`). Browser builds cannot complete real IAP.

## Restore

Paywall includes Restore Purchases (App Store / Play requirement).
